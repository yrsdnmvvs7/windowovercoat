# 窗口外套：主窗口交互设计

状态：设计提案，尚未改动 App 功能。2026-10-11。

## 产品方向

增加一个以试穿预览为中心的原生 macOS 主窗口。用户在这里选择外套、调节边框宽度和针脚大小。根据用户确认，菜单栏保留原有外套总开关、应用子菜单和退出，仅将图案、边框宽度、针脚大小合并为“设置…”入口。默认尺寸建议 960 × 700，可调整大小。

视觉按用户指定改为白色为主的液态玻璃方向：轻透侧栏、白色内容区、圆润悬浮控件、细腻边缘高光和柔和阴影；文字使用中性黑灰，选中态和滑杆使用少量系统蓝。移除米色及绿色界面主题，外套自身配色保持独立。玻璃效果主要集中在导航和控件，内容与预览保持清晰可读。设计稿以浅色展示。正式原生实现优先采用系统提供的材质，并为旧系统、减少透明度和提高对比度设置提供清晰的实色回退。让外套本身的材质和外观成为视觉重点；当前版本展示针织纹理。原型的图案为交互示意，正式版必须复用现有绘制器生成缩略图和预览，避免图示与实际外套不一致。

## 产品命名与扩展原则

产品及全局开关统一使用“窗口外套”，菜单项为“显示窗口外套”。“毛衣 / 针织”只是具体外套类型，不能作为所有外套的统称。

当前版本只有针织外套，不增加只有一个选项的类型选择器。后续新增外套类型时，在外套样式页增加“外套类型”选择；先选类型，再选择该类型的样式。图案与设置项跟随类型变化，避免所有外套都被迫套用针织概念。

边框宽度作为通用设置；针脚大小、毛线配色等只在针织外套下展示。其他类型展示各自有意义的参数。每种类型独立记住上次使用的样式及参数，切回时恢复。试穿预览、应用范围、全局开关、自动保存仍为所有外套共享。

当前交互草稿展示的是针织类型的设置页，不能把其中的针脚控件解读为所有未来外套的公共设置。

## 已有功能依据

当前 `src/menubar.m` 已提供：按应用搭配、平针、罗纹、六种推荐花纹、自定义图案、宽度、针脚大小、全局暂停、各应用开关，以及保存偏好。应用窗口当前使用 Accessory 激活策略，仅显示菜单栏。

按应用模式已有 37 套专属搭配，其他应用自动从图标提取颜色。统一图案仍保留每个应用自己的主毛线颜色，不应向用户承诺统一所有颜色。已有自定义配置优先级继续保留。

## 信息架构

左侧三个入口：外套样式、应用范围、通用设置。启动后的默认页面为外套样式；同一会话再次打开主窗口时保留上次页面。所有页面共享顶部暂停/恢复按钮及底部状态。

### 外套样式

中间浏览样式，右侧试穿预览与细节控制。

1. 两种搭配方式：按应用搭配 / 统一图案。默认沿用用户当前配置，新用户默认按应用搭配。
2. 按应用搭配展示部分专属外套样本及简短说明。样本仅用于预览，不代表将 Finder 的外套应用到所有窗口。点击样本可以切换预览应用，正式版与预览选择器保持同步。
3. 统一图案使用可见纹理卡片展示锯齿纹、野餐格纹、缎带条纹、小蝴蝶结、小星星、糖果条纹、平针、罗纹。图案选中后显示勾选和边框，不仅依靠颜色区分。
4. 有自定义图案时，追加自定义分组。旧图案即使不在推荐列表中，也显示“当前自定义样式”并保留；不得在打开页面时替换设置。
5. 右侧预览固定为模拟窗口，可切换示例应用，查看同一图案在不同配色下的效果。切换预览应用只影响展示，不改变应用规则。无需请求屏幕录制权限，不抓取真实窗口内容。
6. 边框宽度用滑杆展示实时 pt 值，第一版覆盖常用 6–28 pt。已有配置超出此区间时显示实际自定义值，不因初始化控件而截断。
7. 针脚大小保留粗 / 适中 / 细密 / 极细；按当前花纹所需最少行数限制可选项。切换图案时，若现有行数不足则自动调高并显示具体原因。正式版计算应沿用 `max(6, chart.height)`，不是把所有图案都写死为 6 行。

### 应用范围

展示应用图标、名称、当前搭配示意和开关。优先显示正在运行的应用，保留未运行但已有规则的应用。数量较多时提供搜索；应用退出不删除其规则。

“新应用默认开启外套”单独控制未来首次遇到的应用。切换该项时保留当前各应用的明确选择；这与现有“为所有应用开启/关闭”批量重置语义不同，实现时需要状态层支持。

保留“全部开启 / 全部关闭”批量操作，以便用户快速建立白名单。批量操作更新当前列表及默认策略，给予一次撤销，不使用反复确认弹窗。

这里第一版只管理应用启用范围，不新增每个应用独立编辑图案的能力。全局统一图案和应用独立图案的优先级留待后续需求再设计。

### 通用设置

- 登录时启动：拟新增，默认关闭；登录启动只在后台恢复外套。
- 辅助功能权限：显示真实状态。未授权时提供“前往系统设置”，返回后重新检查；允许先浏览和调整模拟预览。
- 说明关闭主窗口后继续运行，并指出菜单栏的重新打开入口。
- 高级自定义：打开现有配置文件和图案目录；加载失败时说明具体问题并保留最后有效设置。

## 核心交互及状态

选择图案 → 卡片选中和预览更新 → 已启用应用的实际外套更新 → 自动保存。无需“应用”或“保存”按钮。拖动宽度时实时更新预览，对实际窗口更新做合适节流，在结束拖动后保存。

切换回按应用模式恢复原来的专属配色，不覆写配置文件；再次进入统一图案时恢复上次选中的统一图案。搭配模式与最后使用的统一图案分别记忆。

暂停是全局状态，不清空样式或各应用规则。暂停期间仍可编辑及保存，显示“恢复后使用当前设置”，预览保持可见；恢复时使用最新选择。

明确区分：正在运行、已暂停、没有启用的应用、需要辅助功能权限。未授权时不得显示“已应用”，应显示“设置已保存，授权后生效”。预览中的应用被关闭时，标注“此应用未启用”，不因试穿自动为其启用。

关闭主窗口不会暂停或退出；主窗口再次打开不得重置图案。彻底退出移除外套并终止后台运行。已有配置在升级后完整保留。

## 菜单栏与 App 生命周期

菜单栏按用户确认保留以下结构：

- 显示窗口外套：保留现有总开关及勾选状态。
- 应用 ▸：保留现有各应用开关、为所有应用开启/关闭等操作。
- 设置…：替换原来的图案、边框宽度、针脚大小三个子菜单。
- 分隔线。
- 退出窗口外套。

“设置…”是直接打开主窗口的菜单项，不再展开下一级子菜单。每次点击都定位到外套样式设置页，使用户能直接找到图案、边框宽度和针脚大小。已有窗口则带到前台并定位该页，未打开则创建或重新显示，不能重复创建多个设置窗口。该明确入口规则优先于一般的恢复上次页面规则。

首次手动启动打开主窗口，并以非阻断方式引导辅助功能授权。后续从应用图标主动启动时把已有主窗口带到前台。建议主窗口显示时出现在 Dock 与 Cmd-Tab 中；窗口关闭后恢复菜单栏后台运行。登录启动不弹窗口。

主窗口中的应用范围页可以作为补充入口，菜单栏原有“应用”子菜单继续保留；两个入口共享同一份应用开关状态。最小首版可优先仅交付外套样式设置页，其余页面作为扩展。

## 第一版范围与落地建议

第一版优先实现外套设置主窗口、图案及预览、边框宽度、针脚大小、菜单栏“设置…”入口、暂停状态和现有配置迁移；菜单栏应用操作继续保留。通用设置先放权限与后台行为，登录启动可作为后续小迭代。暂不加入主题商店、账号、收藏、任意颜色编辑器或每个应用独立图案编辑器。

现有项目主要为 C / Objective-C，可先用 AppKit 增加主窗口。提取菜单栏中的设置更新与持久化为共享状态入口，让主窗口和菜单栏读写同一份状态。预览与生产绘制器共享图案数据和绘制规则，不另做一套纹理实现。具体技术拆分在实现阶段确定。

验收关键场景：旧偏好升级、图案与针脚约束、暂停时修改、关闭窗口仍运行、重新打开无重复窗口、应用开关持久化、权限缺失与恢复、多显示器环境下实际窗口更新。
